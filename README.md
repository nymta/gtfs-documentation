# gtfs-documentation

Documentation for the Metropolitan Transportation Authority (MTA) implementation of GTFS.

This repository supplements the published GTFS and GTFS Realtime (GTFS-RT) specifications with implementation-specific guidance, clarifications, and reference material for MTA feeds.

It is intended to help consumers understand how MTA data maps onto the official standards, not to replace the canonical GTFS or GTFS-RT specs.

Relevant resources:

- [MTA Developers](https://www.mta.info/developers)
- [MTA data feed terms and conditions](https://www.mta.info/developers/terms-and-conditions)
- [GTFS Schedule specification](https://gtfs.org/documentation/schedule/reference/)
- [GTFS Realtime specification](https://gtfs.org/documentation/realtime/reference/)
